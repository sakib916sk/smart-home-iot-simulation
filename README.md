# Smart Home IoT Network Simulation 🌐

A comprehensive Smart Home network topology designed and simulated using **Cisco Packet Tracer**. This project demonstrates how Internet of Things (IoT) devices can be seamlessly integrated into a local network and managed remotely.

## 🚀 Project Overview
The simulation represents a modern smart home environment where various physical home appliances are connected to a central network. Users can monitor and control these devices through a centralized server and a home wireless router.

## 🛠️ Network Components & IoT Devices
- **Networking Hardware:**
  - Home Wireless Router (DHCP enabled)
  - 2950-24 Switch
  - Server-PT (IoT Registration Server)
- **IoT End Devices:**
  - Smart Webcams (Security/Surveillance)
  - Smart Windows & Garage Door (Automated access)
  - Smart Fans & Air Conditioners (Climate control)
  - Smart Lights
  - Smartphone & Laptop (Remote Control & Monitoring)

## ⚙️ Key Features
- **Centralized Control:** All IoT devices are registered to a central Server. 
- **Remote Monitoring:** Devices can be controlled and monitored using a smartphone or laptop connected to the same network.
- **Automated Simulation:** Demonstrates IP addressing, device connectivity, and network protocols within Packet Tracer.

## 📂 How to Run
1. Download the `.pkt` file from this repository.
2. Open it using **Cisco Packet Tracer** (Version 8.0 or higher recommended).
3. Use the PC/Laptop/Smartphone in the simulation to open the IoT Server web interface and log in to control the devices.
